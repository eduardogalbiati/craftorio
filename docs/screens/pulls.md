Every open pull request of the project chosen in the header, by what it needs from you (#812); the entry reads **PRs** on GitHub and **MRs** on GitLab, with a count of the ones that need you (none when nothing does). Three groups: **Need you** (ready to merge, changes requested, a conflict), **Waiting** (CI running, someone else's review) and **Others** (Dependabot, and the pull requests no run opened). Each entry is the Run screen's PR card: its number and title, its branches, its CI, review, conflicts and result lines, what blocks the merge, and **Merge**, **Merge ignoring protection** (only with that permission, asked first) and **Close** (asked first), which work as on a run. A pull request a run opened has **Open the run**, where its **Ask for a fix** stays; one no run opened has no Ask for a fix. Stacked pull requests (#807) sit together, from the bottom (merged first) to the top, and only the bottom one offers Merge. The list is read with `gh pr list` / `glab mr list` (no model call) when the screen opens and every three minutes (a failed read again after 30 seconds), and **Refresh** reads it at once. A project that cannot be read says so with the platform's error, the other projects still listed. Empty states: no open pull request, no remote repository, and no `gh` / `glab` installed. The screen is one column and its buttons wrap, so it works at phone width through the remote address.
