The first screen (#255): one overview of the flow from an idea to a release, with two tabs. **Overview**, for the header's project: the **flow strip** (Inbox → Discovery → Ready → Backlog To do → Running → Merged locally → Released, each stage with its count; a count opens its screen on that stage: the Inbox, the Backlog's board, Workflows › Runs filtered on the runs in progress, Releases; a stage whose screen does not exist yet, the Discovery board, is hidden); **What needs you** (the gates waiting, of every project, with how long they have waited and, while Phone gates is on, the gate's phone link; the discovery cards whose thread ends with a question, e.g. one an agent asked while shaping the idea, until a note answers it; and the roadmap's failed items, each with one button: **Open run**, **Answer** (the Inbox with the card open) or **Open roadmap** (at the item's stage)); **Today** (the real cost of the day and of the last night, i.e. the last Night watch's window or tonight's while it is on, the runs finished and failed, the 24/7 occupancy and the roadmap's next stage); the last Night watch's morning summary; and the Oracle's docked panel. A new workspace (no project, no run) shows how to start instead: create a project, capture a first idea, run a workflow. **Analytics**: the Analytics screen with its own tabs (see Home › Analytics). The start panel opens from Home, Projects › Start, Workflows › Definitions (Run) and the Backlog (#412: the header has no Start button any more): it remembers the workflow, project, `mode` and Advanced parameters between runs; the main task field starts empty for each run. **Start workflow** starts the run and shows it; **Start and create another** starts it and keeps the panel open with the task cleared, to queue several runs in a row (with concurrent runs off, only one can start)
