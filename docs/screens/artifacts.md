Every file a run produced (documents, proposals, reviews, reports), grouped by run and filterable by project. The viewer renders Markdown (tables, table of contents; sanitized with DOMPurify), pretty-prints JSON and shows TSV/CSV as tables. Also listed per run in the project view, in the Run screen's **Artifacts** tab (next to Session and Events, updated live, previewed in place) and on the approval gates that try the change. Right-click a file (or Shift+F10) for **Copy to clipboard** (an image as an image, a text file as its text), **Copy file** (paste it in Explorer or a chat; desktop app only) and **Copy path**; right-click an open image for **Copy image**
