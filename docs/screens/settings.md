Workspace, voice input (**General › Voice input**: OS dictation, the whisper.cpp CLI, model download and language, see Voice input below), CLI status (Claude Code, Codex, Grok Build, GitHub CLI, GitLab CLI, Git) and run preferences (`<workspace>/settings.json`). **General › Backlog › Default development workflow**: the workflow used wherever one is not picked by hand (the Product Owner's plans and its simulated plan, Split + roadmap, Create + roadmap, the Assign dialog with nothing remembered); unset, it is `software-development-local-hero.yaml` (local merge: no push, no PR, no CI minutes) when the workspace has it, else `software-development.yaml`; a saved workflow that was deleted or renamed falls back the same way, and Settings says so. **Execution › Keep awake**: the switch of the Workflows screen (see Workflows), off by default: no sleep while runs, a roadmap or a queue have work to do. **Execution › Concurrent runs**: off by default (one run at a time); on, several workflows run at the same time up to a **maximum** (default 2), with an optional **maximum per project**; simulations count toward the limits only if you say so. Each run has its own git worktree, and the monthly budgets count every run in progress. The **Run** menu item then lists the runs in progress (status, workflow, project/issue): click one to show it on the Run screen and in the top bar (whose **All runs** counter adds them up); a badge counts the human gates waiting across runs, and a gate never pops up over another screen: a toast names its run
