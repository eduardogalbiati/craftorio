# Page security and shared code

No bundler, a window that never navigates, sanitized HTML without forms, the IPC guard and the shared dual-load modules.

- Plain HTML/CSS/JS, no bundler. Libraries loaded with `<script src="../../node_modules/...">`
  (UMD): xterm, addon-fit, marked, DOMPurify. Sandboxed: no Node, only `window.api` (`apps/desktop/host/preload.js`,
  or `api-http.js` over the engine server; a test keeps their method lists equal).
- **The window never navigates** (#466, `apps/desktop/host/window-guards.js` on the main, Agents and connection
  windows): every `will-navigate` is prevented (http(s) goes to the browser), `window.open` is
  denied, no webview attaches (a page's own `location.reload` too: the desktop restarts through
  `app:relaunch`), and `app.js` prevents `dragover`, and `drop` of files or links, at the document so
  a file dropped outside a drop zone is ignored while text still drops into a text box (a zone calls
  its own `preventDefault`; never `stopPropagation` at the document). The CSP meta adds
  `form-action`, `object-src` and `base-uri 'none'`.
- **Untrusted HTML keeps no forms** (#466): agent markdown, READMEs, PR and issue bodies go through
  `sanitizeHtml` (`artifact-render.js`), which forbids `form`, `input`, `button`, `textarea`,
  `select`, `style` and the `action`/`formaction` attributes. The only control markdown keeps is a
  task list's disabled checkbox: marked emits a `data-md-task` marker and `markdownHtml` draws the
  checkbox after sanitizing. Any other control the UI needs is built by the screen's own code.
- **IPC contract** (#467, `apps/desktop/host/ipc-guard.js`): every channel `apps/desktop/host/main.js` registers answers only
  the app's page (`isAppPage`, the Agents window's `?window=agents` included) in a window's top
  frame; another page or a subframe gets an error (an `on` channel: nothing, `sendSync` gets null)
  and one `[ipc]` line in the main log. Register a new channel with `ipc.handle` / `ipc.on`, never
  `ipcMain` directly. The engine server's channels are guarded by its token (#479).
- **Shared modules** (#345): code both the page and the backend use lives in `packages/shared/`, never in
  `apps/desktop/renderer/` (the backend never requires the UI folder). Each is pure (no DOM, no fs, no
  Electron), requires nothing of the app and is dual-load: `module.exports` under Node, a `window`
  global as a `<script>` (copy `packages/shared/display-name.js`). `index.html` loads them first, as
  `<relative path to packages/shared>/<file>.js` (generated by `npm run docs`, which resolves the
  `@multiagent/shared` workspace); the engine server serves `packages/shared/` too.
  The renderer may require only `packages/shared/` (a lazy `require` in a dual-load renderer file);
  `scripts/layers.js` (checked by `test/layers-345.test.js`) holds the areas and their directions.
