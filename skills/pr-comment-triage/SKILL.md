# Review comment triage

The platform skill tells you how to list comments and reply. This skill decides what each one means.
Replies on the PR/MR are in the issues language the Language line names.

## Resume before you classify

Read your own earlier replies and the orchestrator's previous messages first. Do not re-request
a fix that was already made, and do not re-ask the human about a comment they already decided
(fixed, justified or ignored).

## Classify each open comment

| Class | When | Output |
|---|---|---|
| **Actionable** | a concrete, correct request inside the change's scope: a bug, a missing test, a real edge case, a convention the team clearly follows | `needs_fix` |
| **Doubtful** | debatable, out of scope, contradicts another reviewer or the task, or you are not sure it is correct | `needs_human` |
| **Informational** | praise, a question already answered, FYI, status bots (coverage, preview links) | no action |

When in doubt between actionable and doubtful, choose doubtful: a human decides.
Handle one comment per round; the orchestrator calls you again.

## Write a durable fix request

`fix_request` must still make sense after the code moves:
- the comment id and the reviewer's request in one sentence;
- the behaviour that must change and how to verify it (the acceptance criterion);
- the file as a hint, not as the definition of the task.

For a branch that is behind or conflicting, include the intent of both sides (from the commit
messages and the PR/MR titles) so the fixer can preserve both.

## Write the question for the human

`question` = the comment (quoted), who wrote it, and in one or two sentences why you are unsure
and what each option (fix, justify, ignore) would mean.

## Reply after a fix

- Reply on the same thread: what changed and the commit hash ("Fixed in `abc1234`: ...").
- End every reply with the marker `(reply generated by an AI agent)`.
- For a human decision to justify: a short, polite technical justification.
- For a human decision to ignore: no reply.

## Done when

Every open comment is classified, and the state you report is backed by what you read in this round.
