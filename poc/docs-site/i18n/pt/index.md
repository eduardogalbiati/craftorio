# Documentação
App Electron que executa workflows multiagente definidos em YAML (`<workspace>/workflows/`), abrindo
sessões do **Claude Code**, do **Codex CLI** e do **Grok Build** e registrando a observabilidade de cada
sessão (tempo aberto/ativo, tokens, custo, prompts, raciocínio, chamadas de ferramentas, saída).
